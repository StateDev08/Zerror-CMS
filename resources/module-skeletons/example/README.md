# Example Module

Skeleton für den ZerroCMS ZIP-Installer.

- `module.json` – Manifest (`id` = Ordnername)
- `config.json` – ACP-Config-Schema
- `ModuleServiceProvider.php` – muss den Provider-Klassennamen `return`en

Packe den Ordnerinhalt (oder den Ordner `example/`) als ZIP und lade ihn unter **System → Module** hoch.
